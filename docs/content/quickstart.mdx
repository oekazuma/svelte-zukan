svelte-zukan works with plain Vite + Svelte and with SvelteKit 3 or later. It needs Vite 8 or later, Svelte 5.20 or later, and Node 22.17 or later. It uses Vite-specific hooks (`configureServer`, `hotUpdate`, `buildApp`), so it does not work with other bundlers.

## Install

<CodeGroup>

```sh npm
npm install -D svelte-zukan
```

```sh pnpm
pnpm add -D svelte-zukan
```

```sh Yarn
yarn add -D svelte-zukan
```

</CodeGroup>

## Add the plugin

Place `zukan()` before `sveltekit()` or `svelte()`.

<CodeGroup>

```ts SvelteKit
// vite.config.ts
import { sveltekit } from '@sveltejs/kit/vite';
import { defineConfig } from 'vite';
import { zukan } from 'svelte-zukan/vite';

export default defineConfig({ plugins: [zukan(), sveltekit()] });
```

```ts Vite + Svelte
// vite.config.ts
import { svelte } from '@sveltejs/vite-plugin-svelte';
import { defineConfig } from 'vite';
import { zukan } from 'svelte-zukan/vite';

export default defineConfig({ plugins: [zukan(), svelte()] });
```

</CodeGroup>

## Write a catalog file

Put `<Name>.zukan.svelte` next to the component, and wrap each example in `<Section>`.

```svelte
<!-- src/lib/Button/Button.zukan.svelte -->
<script lang="ts">
  import { Section } from 'svelte-zukan';
  import Button from './Button.svelte';
</script>

<Section title="Basic">
  <Button>Click me</Button>
</Section>

<Section title="Disabled">
  <Button disabled>Disabled</Button>
</Section>
```

## Open the catalog

Start the dev server and open `/__zukan/`. The catalog URL is also listed in the URLs printed to the terminal at startup.

If you set Vite's `base` or SvelteKit's `paths.base`, the catalog moves to `<base>__zukan/` (for example, `/app/__zukan/` when `base: '/app/'`).

In the catalog:

- Type in the search box, or press <kbd>/</kbd> to jump to it, to filter the components. <kbd>J</kbd> and <kbd>K</kbd> move to the next and previous component, and <kbd>?</kbd> lists the shortcuts
- A detail page with several sections has a table of contents beside it when the window is wide enough, and links to the previous and next components at the bottom
- Each section has width presets for a phone (375px), a tablet (768px), a laptop (1024px), a desktop (1280px) and the full width (or drag the right edge), a button that outlines every element of the preview, a button that expands it over the page (<kbd>Esc</kbd> leaves), and a link that opens the preview alone in a new tab. The widths are remembered in this browser across reloads
- The theme button at the top of the sidebar switches the catalog and every preview between light and dark. It starts from your system's setting, and your choice is remembered in this browser. On a narrow screen, the component list folds under the menu button
