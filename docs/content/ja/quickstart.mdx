svelte-zukan は、素の Vite + Svelte でも SvelteKit 3 以上でも動きます。Vite 8 以上、Svelte 5.20 以上、Node 22.17 以上が必要です。Vite 専用のフック（`configureServer`、`hotUpdate`、`buildApp`）を使うため、Vite 以外のバンドラーでは動きません。

## インストール

<CodeGroup>

```sh npm
npm install -D svelte-zukan
```

```sh pnpm
pnpm add -D svelte-zukan
```

```sh Yarn
yarn add -D svelte-zukan
```

</CodeGroup>

## プラグインを追加する

`zukan()` は `sveltekit()` や `svelte()` より前に置きます。

<CodeGroup>

```ts SvelteKit
// vite.config.ts
import { sveltekit } from '@sveltejs/kit/vite';
import { defineConfig } from 'vite';
import { zukan } from 'svelte-zukan/vite';

export default defineConfig({ plugins: [zukan(), sveltekit()] });
```

```ts Vite + Svelte
// vite.config.ts
import { svelte } from '@sveltejs/vite-plugin-svelte';
import { defineConfig } from 'vite';
import { zukan } from 'svelte-zukan/vite';

export default defineConfig({ plugins: [zukan(), svelte()] });
```

</CodeGroup>

## カタログファイルを書く

コンポーネントの隣に `<Name>.zukan.svelte` を置き、例ごとに `<Section>` で囲みます。

```svelte
<!-- src/lib/Button/Button.zukan.svelte -->
<script lang="ts">
  import { Section } from 'svelte-zukan';
  import Button from './Button.svelte';
</script>

<Section title="Basic">
  <Button>Click me</Button>
</Section>

<Section title="Disabled">
  <Button disabled>Disabled</Button>
</Section>
```

## カタログを開く

dev サーバーを起動して `/__zukan/` を開きます。起動時にターミナルへ出る URL 一覧にも、カタログの URL が載ります。

Vite の `base` や SvelteKit の `paths.base` を設定しているときは、カタログは `<base>__zukan/`（例: `base: '/app/'` なら `/app/__zukan/`）に移ります。

カタログでは次のことができます。

- 検索欄に入力するとコンポーネントを絞り込めます。<kbd>/</kbd> を押すと検索欄に移ります
- セクションごとに、幅のプリセット（右端のドラッグでも変えられます）、全プレビューに効くライトとダークの背景の切り替え、プレビューだけを新しいタブで開くリンクがあります。背景と幅は、再読み込みしてもこのブラウザーで保たれます
- カタログの UI は OS のライトとダークの設定に合わせます。狭い画面では、コンポーネントの一覧がメニューボタンの中に畳まれます
