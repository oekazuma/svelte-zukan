カタログは dev サーバーの `/__zukan/` で開きます（`base` を設定しているときは `<base>__zukan/`）。このページではカタログでできることを順に説明します。

## トップページ

コンポーネントごとに、最初のセクションの小さなプレビュー、名前とディレクトリ、[`.md` ファイル](/ja/guides/catalog-files#markdown-の説明)の最初の段落を載せたカードが並びます。セクションのないコンポーネントでは、プレビューの代わりに頭文字を表示します。カードをクリックすると詳細ページを開きます。

## コンポーネントを探す

- サイドバーには、コンポーネントがグループとディレクトリごとに並びます。フォルダーは開閉でき、矢印キーで一覧を移動できます
- 検索欄に入力すると、ID とセクション名で絞り込みます。一致したセクション名は各コンポーネントの下に並び、そのセクションへ直接移れます
- セクションが複数ある詳細ページでは、画面の幅に余裕があれば横に目次が出ます。目次には Props の一覧へのリンクもあります。ページの下には前後のコンポーネントへのリンクがあります
- 狭い画面では、コンポーネントの一覧がメニューボタンの中に畳まれます

### 幅

- プリセットはスマートフォン（375px）、タブレット（768px）、ノート PC（1024px）、デスクトップ（1280px）、全幅です。幅は右端のつまみをドラッグしたり、プリセットの横の数値欄に px で入力したりしても変えられます
- ページより狭い幅のプレビューはドット柄の背景の中央に置くので、広い画面でも端末の端が分かります
- ページより広い幅のプレビュー（ノート PC でのデスクトップのプリセットなど）は、その幅で描画してから縮小して表示します。縮小率は幅の横に出ます
- 幅はこのブラウザーのタブで再読み込みしても保たれるので、編集の間もプレビューの幅は変わりません

### そのほかのボタン

| ボタン           | 働き                                                                                           |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| 背景             | プレビューの背景を、テーマの色、市松模様（透過の確認用）、グリッドで切り替えます               |
| アクセシビリティ | [アクセシビリティパネル](#アクセシビリティパネル)を開きます                                    |
| 計測             | カーソルを当てた要素のサイズを表示し、margin・border・padding を開発者ツールと同じ色で塗ります |
| 枠線             | プレビュー内のすべての要素に枠線を出します                                                     |
| 拡大             | プレビューを画面いっぱいに広げます。<kbd>Esc</kbd> か枠の外のクリックで戻ります                |
| リンクをコピー   | 今の幅とテーマのまま、このセクションへのリンクをコピーします                                   |
| 新しいタブで開く | プレビューだけを、カタログのテーマで開きます                                                   |

コピーしたリンクを開くと、そのリンクの幅とテーマでセクションを表示します。テーマはそのタブにだけ適用されるので、自分で選んだテーマは変わりません。このリンクは手で書くこともできます。`section` のあとに `width` と `theme` を付けて、`#/ui/Card?section=Basic&width=375&theme=dark` のように書きます。

## アクセシビリティパネル

アクセシビリティのボタンを押すと、プレビューの中で [axe-core](https://github.com/dequelabs/axe-core) を動かし、見つかった問題を一覧にします。一覧には深刻度、説明、詳しい説明へのリンク、該当する要素が並びます。

  width="1280"

/>

- 問題のある要素はプレビューの中で深刻度の色の枠で囲まれます。一覧の要素にカーソルを当てるかフォーカスすると枠が太くなり、クリックすると太いまま残って、その位置までスクロールします
- パネルを開いている間は、編集でプレビューが再読み込みされるたびに検査し直します
- 「見え方」ではぼやけた視界や色覚特性（P 型、D 型、T 型、1 色覚）での見え方を再現します。各チップにはその見え方での色の見本があります
- `locale: 'ja'` のときは、axe-core の指摘も日本語になります

axe-core は検査を実行したときにだけ読み込みます。ページのすべての内容をランドマークで囲むよう求めるルールは、単体のコンポーネントには当てはまらないので外しています。

## テーマ

サイドバー上部のテーマボタンで、カタログとすべてのプレビューをライトとダークで切り替えます。最初は OS の設定に合わせ、選んだテーマはこのブラウザーで保たれます。テーマは各プレビューの `color-scheme` になるので、コンポーネントの `light-dark()` や `prefers-color-scheme` もこれに従います。

## キーボードショートカット

| キー                        | 動作                                           |
| --------------------------- | ---------------------------------------------- |
| <kbd>/</kbd>                | 検索欄に移る                                   |
| <kbd>J</kbd> / <kbd>K</kbd> | 次 / 前のコンポーネント                        |
| <kbd>T</kbd>                | ライトとダークを切り替える                     |
| <kbd>F</kbd>                | 表示中のプレビューを拡大する（もう一度で戻る） |
| <kbd>Esc</kbd>              | 拡大したプレビューから戻る                     |
| <kbd>↑</kbd> <kbd>↓</kbd>   | コンポーネントの一覧を移動する                 |
| <kbd>←</kbd> <kbd>→</kbd>   | 一覧のフォルダーを閉じる・開く                 |
| <kbd>?</kbd>                | ショートカットの一覧を出す                     |

検索欄などに入力している間は、ショートカットは働きません。
