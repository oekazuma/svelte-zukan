カタログは dev サーバーの `/__zukan/` で開きます（`base` を設定しているときは `<base>__zukan/`）。このページでは、トップページ、コンポーネントの探し方、テーマ、キーボードショートカットを説明します。各プレビューには[専用のツールバー](/ja/previews)があり、[アクセシビリティパネル](/ja/accessibility)もそこから開きます。

## トップページ

コンポーネントごとに、最初のセクションの小さなプレビュー、名前とディレクトリ、[`.md` ファイル](/ja/catalog-files#markdown-の説明)の最初の段落を載せたカードが並びます。セクションのないコンポーネントでは、プレビューの代わりに頭文字を表示します。カードをクリックすると詳細ページを開きます。

カードの下には、探索するディレクトリにある `.svelte` ファイルのうち、隣にまだカタログファイルがないものを畳んだ一覧で出します。カタログにまだ載せていないものが分かります。SvelteKit のルートのファイル（`+page.svelte`）、テスト用のコンポーネント、`src/routes/` は含めません。

## コンポーネントを探す

- サイドバーには、コンポーネントがグループとディレクトリごとに並びます。フォルダーは開閉でき、矢印キーで一覧を移動できます
- 検索欄に入力すると、ID とセクション名で絞り込みます。一致したセクション名は各コンポーネントの下に並び、そのセクションへ直接移れます
- セクションが複数ある詳細ページでは、画面の幅に余裕があれば横に目次が出ます。目次には Props の一覧へのリンクもあります。ページの下には前後のコンポーネントへのリンクがあります
- dev サーバーでは、詳細ページのタイトルの下に、カタログファイルとコンポーネントをエディターで開くボタンがあります。Vite 自身のエディターで開く仕組みを使うので、開くエディターは環境変数 `LAUNCH_EDITOR` で選べます。静的に書き出したカタログには、このボタンはありません
- 狭い画面では、コンポーネントの一覧がメニューボタンの中に畳まれます

## テーマ

サイドバー上部のテーマボタンで、カタログとすべてのプレビューをライトとダークで切り替えます。最初は OS の設定に合わせ、選んだテーマはこのブラウザーで保たれます。テーマは各プレビューの `color-scheme` になるので、コンポーネントの `light-dark()` や `prefers-color-scheme` もこれに従います。

テーマを 1 つに決めたいときは、[`theme` オプション](/ja/options)に `'light'` か `'dark'` を指定します。カタログとすべてのプレビューが常にそのテーマになり、テーマボタンと <kbd>T</kbd> のショートカットはなくなります。

## キーボードショートカット

| キー                        | 動作                                                               |
| --------------------------- | ------------------------------------------------------------------ |
| <kbd>/</kbd>                | 検索欄に移る                                                       |
| <kbd>J</kbd> / <kbd>K</kbd> | 次 / 前のコンポーネント                                            |
| <kbd>T</kbd>                | ライトとダークを切り替える（`theme` オプションの指定時は使えない） |
| <kbd>F</kbd>                | 表示中のプレビューを拡大する（もう一度で戻る）                     |
| <kbd>Esc</kbd>              | 拡大したプレビューから戻る                                         |
| <kbd>↑</kbd> <kbd>↓</kbd>   | コンポーネントの一覧を移動する                                     |
| <kbd>←</kbd> <kbd>→</kbd>   | 一覧のフォルダーを閉じる・開く                                     |
| <kbd>?</kbd>                | ショートカットの一覧を出す                                         |

検索欄などに入力している間は、ショートカットは働きません。
