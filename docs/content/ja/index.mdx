## AI エージェントにカタログを書かせる

[スキル](/ja/ai-agents#スキル)を入れて、Claude Code、Cursor、Codex などのエージェントに「svelte-zukan を入れて、コンポーネントをカタログに載せて」と頼みます。エージェントは、プロジェクトに合ったオプションでプラグインを追加し、コンポーネントごとにカタログファイルを書き、props の JSDoc と `.zukan.md` ファイルで説明を付け、結果を確かめます。

```sh
npx skills add oekazuma/svelte-zukan
```
