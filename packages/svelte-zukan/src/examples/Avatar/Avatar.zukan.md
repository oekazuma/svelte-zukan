Shows a person by picture or, without one, by initials on a color that is derived from the name, so the same person always gets the same color.

- `name`: used for the initials, the color and the accessible name
- `src`: an optional image URL
- `size`: `sm`, `md` (default), `lg` or `xl`
- `status`: `online`, `away` or `offline`

`AvatarGroup` stacks avatars and folds the rest into a `+N` count (`max`, default 4).
