A surface that groups related content: an optional cover, a title, a body and a footer for actions.

- `title`, `eyebrow`: the heading and the small text above it
- `cover`: any CSS background, such as a gradient or `url(...)`
- `horizontal`: puts the cover beside the content when the card is wider than 520px. The layout uses a container query, so it follows the card's own width, not the window's. Try the width presets on the "Responsive" section.
- `footer`: a snippet for prices, tags and buttons
