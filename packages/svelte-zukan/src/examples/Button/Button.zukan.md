The button of the example design system. Every attribute of `<button>`, such as `disabled` or `onclick`, is passed through.

- `variant`: `primary` for the main action of a screen, `secondary` (default), `ghost` for low-emphasis actions, `danger` for destructive ones
- `size`: `sm`, `md` (default) or `lg`
- `loading`: shows a spinner and blocks clicks until the work is done
- `icon`: a snippet rendered before the label

Use one primary button per screen.
